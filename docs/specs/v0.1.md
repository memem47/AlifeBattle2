# AlifeBattle v0.1 Specification

## Goal

Create the smallest complete AlifeBattle simulation.

> Twenty agents. Two teams. Move, fight, die, win.

## Battlefield

- Red: 10 agents
- Blue: 10 agents
- Red starts on the left.
- Blue starts on the right.
- Starting positions are randomized within each team's starting area.
- A fixed random seed may be used when reproducible behavior is needed for debugging or testing.

## Agent Rules

All agents have identical parameters.

| Parameter | Value |
| --- | ---: |
| HP | 100 |
| Speed | 28 px/s |
| Attack Damage | 20 |
| Attack Range | 12 px |
| Attack Interval | 1.0 s |

Each living agent:

1. selects the nearest living enemy on every simulation update,
2. moves toward it if outside attack range,
3. attacks it when in range and cooldown is zero.

Agents die when HP reaches zero.

## Battle Result

- Red wins when no Blue agents remain alive.
- Blue wins when no Red agents remain alive.
- If both teams die in the same update, the result is a draw.

## UI

Display:

- Agents are drawn as triangles pointing in their current movement direction.
- Agent color indicates remaining health using three damage levels.
- Team identity must remain visually distinguishable at every health level.
- Dead agents remain visible at the position where they died and are shown using a distinct death marker.
- The surviving agent count is displayed,
- The battle result is displayed.

Controls:

- `R`: restart
- `Esc`: quit

## Constraints

- Movement must use delta time.
- Simulation behavior must not depend on rendering FPS.
- Agents should avoid excessive overlap with nearby agents.
- Individual agents should remain visually distinguishable during battle.
- Brief contact or small overlap are acceptable; strict physical collision is not required.
- No performance optimization is required for 20 agents.

## Out of Scope

- formations,
- morale,
- retreat,
- individual traits,
- tactical commands,
- terrain,
- pathfinding,
- spatial grids.

## Done When

The program can run a complete 10-vs-10 battle from start to finish and restart it.
