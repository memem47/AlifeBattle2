# AlifeBattle v0.4 Specification

## Goal

Introduce the first player-controllable battle commands.

The player can switch each team's movement behavior between:

- `ADVANCE`
- `HOLD`

This version establishes the basic command mechanism without introducing formations, units, command queues, or complex tactics.

## Initial State

At the start of a battle:

- Red command is `ADVANCE`.
- Blue command is `ADVANCE`.

This preserves the default behavior of v0.3.

## Commands

### ADVANCE

The team moves in its normal forward direction:

- Red moves right.
- Blue moves left.

Living agents physically block movement.

An agent may move only as far as it can without overlapping another living agent.

### HOLD

The team has no commanded movement.

A holding agent remains in place and acts as a physical obstacle to other living agents.

Local attack targeting remains active, so agents can still attack enemies within `ATTACK_RANGE`

## Physical Occupancy

Living agents have physical size.

For v0.4, agents are treated as circular occupants using `AGENT_RADIUS`.

Two living agents must not move into positions where their center distance is smaller than `SEPARATION_DISTANCE`.

Blocking applies regardless of team.

Dead agents do not block movement. A living agent may occupy or pass through the position of a dead agent.

Movement blocking limits commanded movement before overlap occurs.
The simulation should not normally move agents into penetration and then repeatedly push them apart. When agents move in the same direction, front agents are resolved before rear agents Rear agents may move into space vacated by agents in front of them.

If a front agent cannot advance, that movement restriction propagates to agents behind it.

Opposing moving agents are treated as moving simultaneously. Neither team receives priority because of update order.

Movement blocking does not change facing direction.

## Player Input

Keyboard controls:

- `A`: toggle Red between `ADVANCE` and `HOLD`
- `B`: toggle Blue between `ADVANCE` and `HOLD`
- `R`: reset the battle

Each key press changes only the selected team's command.

## Command Visibility

The current command for each team should be visible on screen.

Example:

```text
Red: ADVANCE
Blue: HOLD
```

## Combat

The v0.3 combat model remains unchanged:

- attack targets are searched locally,
- only enemies within attack range can be targeted,
- movement does not depend on attack targets.

## Scope

v0.4 includes:

- persistent command state for each team,
- `ADVANCE`,
- `HOLD`,
- keyboard command switching,
- visible current command state.

## Out of Scope

- `RETREAT`,
- left/right maneuver commands,
- formations,
- multiple units,
- command duration,
- command queues,
- commander AI,
- morale,
- terrain.

## Done When

v0.4 is complete when:

- both teams start in ADVANCE,
- pressing `A` toggles the Red command,
- pressing `B` toggles the Blue command,
- `ADVANCE` produces forward movement,
- `HOLD` removes commanded forward movement,
- living agents never move through other living agents,
- blocking applies to both allies and enemies,
- dead agents do not block movement,
- rear agents reach contact without update-order bias,
- `HOLD` produces zero command movement,
- local combat continues while holding,
- movement blocking does not change facing direction,
- current commands are visible,
- existing v0.3 behavior remains unchanged otherwise.
