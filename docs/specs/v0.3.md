# AlifeBattle v0.3 Specification

## Goal

Separate movement from combat targeting.

Agents should move according to command intent rather than searching the battlefield for the nearest enemy.

## Command-Driven Movement

v0.3 uses one fixed command for each team:

- Red advances to the right.
- Blue advances to the left.

Agents do not select an enemy in order to decide where to move.

Movement direction is determined only by the current team command.

## Combat

Combat targeting is local.

After movement:

1. an agent checks nearby enemies,
2. only enemies within `ATTACK_RANGE` are valid attack targets,
3. if multiple valid enemies exist, the nearest one is selected,
4. the normal cooldown and damage rules are applied.

Attack-target selection must not influence movement direction.

## Separation

The existing separation behavior remains active.

The spatial grid continues to be used for local-neighbor lookup.

## Scope

v0.3 includes:

- fixed team-level advance commands,
- command-driven movement,
- local attack-target detection,
- removal of global nearest-enemy targeting from movement.

## Out of Scope

- player-selectable commands,
- retreat,
- hold,
- left/right maneuver commands,
- formations,
- multiple units,
- morale,
- terrain,
- commander AI.

## Done When

v0.3 is complete when:

- Red agents advance right without globally searching for enemies,
- Blue agents advance left without globally searching for enemies,
- agents attack only enemies that enter local attack range,
- movement direction is independent of attack target selection,
- battles still complete,
- existing separation and combat rules continue to work.
