# AlifeBattle v0.2 Specification

## Goal

Validate that the v0.1 battle model remains understandable and usable with larger armies.

## Changes from v0.1

- Increase Red from 10 to 50 agents.
- Increase Blue from 10 to 50 agents.
- Adjust the initial placement area if necessary so that agents remain visually distinguishable.

All movement and combat rules remain unchanged from v0.1.

## Requirements

- A 50-vs-50 battle can run from start to finish.
- Individual agents remain reasonably distinguishable.
- Agents do not become permanently stuck because of separation behavior.
- The battle remains responsive enough to observe in real time.
- Existing v0.1 simulation behavior remains unchanged.

## Performance

- The current FPS is displayed during battle.
- Large battles are used to identify actual performance bottlenecks.
- Performance improvements must preserve the existing simulation behavior

## Out of Scope

- Spatial partitioning
- Formations
- Morale
- Retreat
- Directional combat
- Tactical commands
- Terrain
- New combat rules

## Done When

A complete 50-vs-50 battle can be observed from start to finish without introducing new gameplay systems or unnecessary optimization.
