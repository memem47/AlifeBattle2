# AlifeBattle v0.2 Design

## Approach

v0.2 reuses the v0.1 architecture without introducing new simulation systems.

The initial implementation change only the army size and, if necessary, configuration values related to initial placement and visualization.

## Architecture

No architectural changes are planned.

The existing structure remains:

```text
main.py
 ├─ Game
 │   └─ Agent[]
 └─ renderer
```

## Scaling

`TEAM_SIZE` is increased from 10 to 50.

The existing nearest-enemy search and separation algorithms are retained initially.

No performance optimization is introduced until an actual performance problem is observed.

## Performance Measurement

FPS is obtained from the Pygame clock in `main.py` and passed to the renderer.

Performance information is for observation only and is not part of the simulation state.

## Evaluation

After the 50-vs-50 version is implemented, evaluate:

- battle completion,
- simulation responsiveness,
- visual distinguishability,
- agent overlap,
- separation behavior,
- and any obvious performance bottlenecks

If a problem is found, identify its cause before changing the architecture.
