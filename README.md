# AlifeBattle2

A small real-time artificial-life battle simulation developed incrementally as a software engineering learning project.

## Setup

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Test

```bash
python -m pytest
```
